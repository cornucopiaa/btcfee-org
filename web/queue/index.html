This page provides a real-time visualization of unconfirmed cryptocurrency transactions, commonly referred to as the mempool. The mempool holds transactions that are yet to be written to the blockchain and are temporarily stored in volatile memory. BTCfee.org offers insights into how the mempool evolves over time, helping users understand transaction dynamics.

Understanding the Mempool

  • What is the Mempool?

    The mempool is a collection of unconfirmed transactions waiting to be processed and included in a block. Since decentralized cryptocurrencies do not have a universal mempool, each node maintains its own set of transactions it has seen. The mempool data displayed here is sourced directly from a full node and is updated every minute. Note that the mempool is reset when the node is restarted.

  • How Transactions Are Represented:

    Transactions are color-coded by their fee rate (measured in satoshis per virtual byte).

    • Low-fee transactions are displayed at the bottom.
    • High-fee transactions are stacked on top, as miners prioritize them.

  • Mempool Dynamics:

    A new block usually clears the highest-fee transactions, removing approximately 1 MB of data from the top of the queue. If lower-fee transactions remain visible over several hours without shrinking, it indicates that higher-paying transactions are consistently taking precedence.

Interactive Features

  • Dynamic Charts:

    The horizontal axis represents time (selectable from the last 2 hours to the full dataset), while the vertical axis can be switched between:

    • Count: Number of transactions.
    • Fee: Total transaction fees.
    • Weight: Total transaction size, reflecting the segwit discount.
  • In the weight chart, a larger stripe compared to the count chart signifies larger-than-average transactions. Similarly, a higher stripe on the fee chart reflects higher cumulative fees.

  • Customizable Views:

    Users can click on a fee rate in the legend to hide all lower fee rates. This allows for a clearer view of transactions competing at a specific fee level.

Mempool Size Limit

  • The default mempool size for a Bitcoin node is 300 MB, but this size is calculated differently than block size:

    • No SegWit Discount: The mempool size includes the full transaction size.
    • Effective Size: The 300 MB mempool limit translates to approximately 50–120 vMB, depending on transaction structure.

What are cryptocurrency transaction fees?

Weight is a measure of transaction size, reflecting how much space it occupies in a block. Larger transactions typically require higher fees.

What does 'weight' mean in Bitcoin transactions?

Transaction fees are the costs associated with processing transactions on a blockchain network. They incentivize miners or validators to include your transaction in the next block.
